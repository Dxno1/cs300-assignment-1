## Component
Option B: Product Card

FocusDesk Study Planner is a product card designed for college students. It presents a study planner with product information, features, and an Add to Cart link.

## Live Website
[View FocusDesk Product Card](https://dxno1.github.io/cs300-assignment-1/)

## Design Choices
I designed the product card with a clean and simple layout. It includes a product image, product name, price, description, five product features, and an Add to Cart button.

The color palette uses blue, white, and light gray. These colors provide contrast and make the content easy to read.

I used the Inter web font from Google Fonts for consistent typography.

## HTML Structure
The component uses semantic HTML5 elements, including:
- main
- article
- figure
- figcaption
- section
- h1
- p
- ul
- li
- a

The product image includes alternative text to support screen reader users.

## CSS Styling
The external styles.css file controls the product card's appearance.

The CSS box model uses:
- Padding
- Margins
- Borders
- Width and height
- Border radius

The stylesheet also uses CSS Grid, multiple selector types, and a responsive media query.

## Hover Effects
The product card lifts slightly and receives a stronger shadow when hovered over.

The Add to Cart button changes its background color, position, and shadow when hovered over.

Transitions make these interactions smoother.

## Responsive Design
The product card uses two columns on larger screens. A media query changes the layout to one column on screens 700 pixels wide or smaller.

The smaller layout places the product image above the product information.

## Accessibility
The component includes descriptive image alt text, semantic HTML, visible keyboard focus styling, and support for reduced motion.
