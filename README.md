## Design Choices
I've ‌made ‌the ‌product card simple and clean. It has the image of the product, the product name, price, description, five product features and Add to Cart button.

I've used the color pallet of blue, white and gray which provides good contrast and easy to read.

I've used the Inter web font for typography.

The markup uses semantic HTML5 elements like main, article, figure, section, h1, ul, li and a.

The box model is shown in the CSS through padding, margins, borders, width, height and border-radius.

I've added hover effects for the product card and Add to Cart button. It will be a single column layout on small screens. So, it is mobile friendly. It has a visible focus outline on keyboard interaction and supports reduced motion.
